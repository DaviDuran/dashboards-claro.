Contexto y Alcance del Proyecto SED

CONTEXTO: Se requiere visitar las 225 sedes y corregir observaciones tecnicas estandarizadas por el cliente para los enlaces entregados durante la implementacion del año 2025, para cada sede se debe generar un formato con evidencias fotograficas el cual se debe enviar a nterventoria para su aprobacion. ALCANCE: 225 Sedes, 450 Enlaces, 225 Remediaciones, Fecha limite para la aprobacion 18/09/2026. PARTICULARIDADES: La generacion del cronograma se realizara desde la Regional, teniendo un minimo de 4 remediaciones diarias. El tiempo de indisponibilidad de cada remediacion, no debe superar las 2 horas, si se tiene una ventana mayor a ese tiempo, se debe reportar con anterioridad y enviar un informe con la justficacio del tiempo de desconexion.
